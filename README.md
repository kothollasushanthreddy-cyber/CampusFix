# CampusFix

CampusFix is a campus maintenance issue reporting and tracking web application.

## Problem
Students need a simple way to report campus maintenance issues and track their progress.

## Planned Features
- Report maintenance issues
- View submitted reports
- Track issue status
- Administer issue updates

## Technology Stack
- Frontend: HTML, CSS, JavaScript, and React
- Backend: Node.js and Express
- Database: PostgreSQL
- Version Control: Git and GitHub
